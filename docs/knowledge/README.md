# Knowledge base

Aquí viven explicaciones y experimentos reutilizables. Un knowledge note explica
un fundamento; no registra una decisión ni sustituye documentación operativa.

## Tipos de nota

- concepto;
- comparación;
- experimento;
- fallo estudiado;
- lectura comentada.

## Criterios de calidad

- pregunta de aprendizaje concreta;
- explicación con palabras propias;
- ejemplo o evidencia;
- límites y contraejemplos;
- aplicación al proyecto;
- fuentes primarias cuando corresponda;
- fecha de revisión si el tema cambia con versiones.

Usa [template.md](template.md). Las conclusiones que cambien arquitectura pasan por
ADR; los pasos operativos pasan a un runbook.
